# Plano: Sistema de Período de Teste (Trial) por Tenant/Empresa

## Objetivo
Implementar um período de teste de 1 mês por empresa/tenant, com bloqueio de acesso ao painel quando expirado. Configuração via banco de dados.

---

## Passo 3: Model `Company`

**Arquivo:** `app/Models/Company.php`

```php
class Company extends Model
{
    protected $fillable = ['name', 'slug', 'email', 'phone', 'cnpj', 'trial_starts_at', 'trial_ends_at', 'active'];
    protected $casts = ['trial_starts_at' => 'datetime', 'trial_ends_at' => 'date'];

    public function users() { return $this->hasMany(User::class); }
    public function isTrialExpired() { return $this->trial_ends_at && $this->trial_ends_at->isPast(); }
    public function trialDaysLeft() { return $this->trial_ends_at ? max(0, now()->diffInDays($this->trial_ends_at, false)) : 0; }
}
```

## Passo 5: Middleware `CheckTrial`

**Arquivo:** `app/Http/Middleware/CheckTrial.php`

```php
class CheckTrial {
    public function handle($request, Closure $next) {
        $user = $request->user();
        if (!$user || !$user->company) return $next($request);
        
        if ($user->company->isTrialExpired()) {
            return redirect()->route('trial.expired');
        }
        return $next($request);
    }
}
```
