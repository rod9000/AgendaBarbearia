# Plano: WhatsApp - Notificações com Links

## Objetivo
Enviar mensagens WhatsApp com links de confirmação, cancelamento e reagendamento.

---

## Links do Sistema

| Link | Rota | Função |
|------|------|--------|
| `/confirmar/{token}` | `PublicController::confirmar` | Confirma presença |
| `/cancelar/{token}` | `PublicController::cancelar` | Cancela agendamento |
| `/reagendar/{token}` | `PublicController::reagendar` | Reagenda horário |

## Passo 3: Criar Método `cancelar()` no PublicController

**Arquivo:** `app/Http/Controllers/PublicController.php`

```php
public function cancelar($token)
{
    $appointment = Appointment::where('confirmation_token', $token)->firstOrFail();
    
    if ($request->isMethod('post')) {
        $appointment->update(['status' => 'cancelled']);
        
        // Enviar confirmação de cancelamento
        $wa = app(WhatsAppService::class);
        $wa->send($appointment->customer->phone,
            "❌ Seu agendamento foi cancelado.\n" .
            "Data: {$appointment->start->format('d/m/Y H:i')}\n\n" .
            "Para reagendar: " . url('/reagendar/' . $token)
        );
        
        return view('public.cancelamento', ['appointment' => $appointment, 'cancelled' => true]);
    }
    
    return view('public.cancelamento', ['appointment' => $appointment, 'cancelled' => false]);
}
```

### sendCancellation() — Criar método
```php
public function sendCancellation(Appointment $appointment): bool
{
    $appointment->load('services', 'customer');
    $serviceList = $appointment->services->pluck('name')->implode(', ');
    
    $msg = "Olá {$appointment->customer->name}, seu agendamento foi cancelado.\n"
         . "Serviço: {$serviceList}\n"
         . "Data: {$appointment->start->format('d/m/Y H:i')}\n\n"
         . "🔄 Para reagendar:\n"
         . url('/reagendar/' . $appointment->confirmation_token);
    
    return $this->send($appointment->customer->phone, $msg);
}
```
