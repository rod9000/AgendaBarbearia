# Plano: Script para Popular Agenda em 1 Mês

## Objetivo
Criar um script PHP que gera agendamentos aleatórios para os próximos 30 dias, usando os serviços, clientes e profissionais já cadastrados no banco.

---

## Estrutura do Banco (tabelas relevantes)

### `appointments`
- `customer_id` (FK → customers)
- `user_id` (FK → users, profissional)
- `service_id` (FK → services)
- `start` (datetime)
- `end` (datetime)
- `status` (enum: scheduled, confirmed, etc.)
- `notes` (text, nullable)

### `services` (já cadastrados: 12 barbearia)
- `id`, `name`, `duration_min`, `price`

### `customers` (cadastrados no sistema)
- `id`, `name`, `cpf`

### `users` (profissionais com role=attendant)
- `id`, `name`, `role`

---

## Script PHP: `seed_appointments.php`

### Lógica
1. Buscar todos os serviços ativos
2. Buscar todos os clientes
3. Buscar todos os profissionais (attendant)
4. Para cada dia dos próximos 30 dias:
   - Gerar entre 3 e 8 agendamentos aleatórios
   - Horários entre 09:00 e 19:00
   - Cliente, profissional e serviço escolhidos aleatoriamente
   - Duração baseada no serviço
   - Status: scheduled

### Arquivo
`tmp/seed_appointments.php`

### Upload
Enviar para `/htdocs/tmp/seed_appointments.php` no Infinity Free e acessar via navegador.

---

## Verificação
1. Acessar `https://agendabarbearia.infinityfree.me/tmp/seed_appointments.php`
2. Verificar no painel admin → Agenda se os agendamentos aparecem
3. Deletar o script após uso (segurança)
