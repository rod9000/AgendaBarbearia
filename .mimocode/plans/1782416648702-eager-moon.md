# Bot WhatsApp com Evolution API - Plano de Implementação

## Contexto

O projeto **AgendaBarbearia** já possui integração **unidirecional** com Evolution API (envio de mensagens via `WhatsAppService`). Falta criar o **receptor** (webhook) e o **motor do bot** para atender clientes via WhatsApp com fluxo de agendamento completo.

O Docker da Evolution API já está configurado em `docker/evolution/docker-compose.yml`, mas falta:
- Criar `.env` na pasta docker/evolution
- Configurar webhook no docker-compose
- Criar endpoint webhook no Laravel
- Criar o motor de conversação do bot

---

## Fluxo do Bot

```
Cliente envia msg → Evolution API → POST /api/webhook/evolution
                                          ↓
                                   BotHandler.php
                                   (verifica estado da conversa)
                                          ↓
                              ┌─────────────────────────────┐
                              │  ESTADO: INITIAL            │
                              │  → Menu de boas-vindas      │
                              │    1-Agendar 2-Horários     │
                              │    3-Preços 4-Consultar     │
                              │    5-Cancelar 6-Localização │
                              └──────────┬──────────────────┘
                                         ↓ (escolha do usuário)
                              ┌─────────────────────────────┐
                              │  ESTADO: CHOOSING_SERVICE   │
                              │  → Lista serviços disp.     │
                              │  (usa Service::all())       │
                              └──────────┬──────────────────┘
                                         ↓
                              ┌─────────────────────────────┐
                              │  ESTADO: CHOOSING_DATE      │
                              │  → Pede data (DD/MM)        │
                              │  → Mostra horários disp.    │
                              └──────────┬──────────────────┘
                                         ↓
                              ┌─────────────────────────────┐
                              │  ESTADO: CHOOSING_TIME      │
                              │  → Lista horários livres    │
                              └──────────┬──────────────────┘
                                         ↓
                              ┌─────────────────────────────┐
                              │  ESTADO: CONFIRMING         │
                              │  → Resumo + Confirmar/Menu  │
                              └─────────────────────────────┘
```

## Arquitetura

```
Evolution API (Docker)
        │ POST /api/webhook/evolution
        ↓
routes/api.php
        │
        ↓
WebhookController (recebe + valida payload)
        │
        ↓
BotHandler.php (Service)
        │
        ├── ConversationService.php (gerencia estado)
        │       ├── conversations table (state, context, expires_at)
        │       └── messages table (in/out)
        │
        ├── Routing (state machine)
        │       ├── handleInitialMenu()
        │       ├── handleChoosingService()
        │       ├── handleChoosingDate()
        │       ├── handleChoosingTime()
        │       ├── handleConfirming()
        │       ├── handleConsultingAppointments()
        │       ├── handleCancelling()
        │       ├── handleInfo()
        │       └── handleOffHours()
        │
        └── WhatsAppService::send() (resposta)
```

4. **Configurar no Admin**: Acessar `/admin/settings/bot`, habilitar bot e configurar mensagens
