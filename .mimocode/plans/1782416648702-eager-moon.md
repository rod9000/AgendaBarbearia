# Melhorias: Cache Redis + Relatório Financeiro

## 1. Cache Redis no Railway

### O que já existe
- `config/cache.php` já tem store Redis configurado
- Railway oferece plugin Redis gratuito
- Não tem `predis/predis` no composer.json

### Alterações necessárias

#### `composer.json`
- Adicionar `"predis/predis": "^2.0"`

#### `.env` (Railway Variables)
```
CACHE_DRIVER=redis
REDIS_HOST=redis.railway.internal
REDIS_PORT=6379
REDIS_PASSWORD=<do plugin Redis>
```

#### Onde aplicar cache
- **Dashboard KPIs**: `DashboardController` — cache 5min nos totais
- **Services list**: `Service::all()` — cache 1h
- **Working hours**: `WorkingHour::all()` — cache 1h
- **Bot menu items**: `BotMenuItem::all()` — cache 1h

### Arquivos a modificar
- `composer.json`
- `app/Http/Controllers/Admin/DashboardController.php`
- `app/Http/Controllers/Admin/ServiceController.php`
- `app/Services/Bot/BotHandler.php`
