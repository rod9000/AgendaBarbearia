# Fix: Customer name always showing "Cliente WhatsApp"

## Problem
Customer names from WhatsApp are always "Cliente WhatsApp" instead of using `pushName` from Evolution API.

## Root Cause
In `WebhookController.php`, `pushName` is extracted from `$data['pushName']`. In `ConversationService.php`, the name is only used when creating a new customer, but not always updated when `pushName` changes. Also need to extract pushName from deeper in the payload as fallback.

## Files to modify

### 1. `app/Http/Controllers/Api/WebhookController.php`
- Add fallback extraction: also check `data.context.pushName` and `data.pushName`
- Log pushName value for debugging

### 2. `app/Services/Bot/ConversationService.php`
- Always update customer name when pushName is provided, non-empty, and different from "Cliente WhatsApp"
- Use `resolveName()` helper to pick best available name

## Verification
Send test webhook with `pushName: "João Silva"` → check customer name in DB
